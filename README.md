# BioMaths-Tallulah-Bagg-Nanette-Malan
# Biomathematics Project – Tallulah Bagg and Nanette Malan

## Repository Files

**R code**
- `BioCode_2.R` – R script containing file and data preparation, testing of models, final models and testing for each hypothesis and graphs
- `BioMaths-Tallulah-Bagg-Nanette-Malan(2).Rproj` – RStudio project file.

**Datasets**
- `TIR every day.xlsx` – Refined daily CGM data used for the Bionic Pancreas versus control analysis and the analysis of patients aged under 65 versus 65 and over analysis (Hypotheses 1 and 2)
- `BPFIASP_TIR.xlsx` – Refined daily CGM data used to compare the Bionic Pancreas and BPFiasp treatment groups (Hypothesis 3).

**Figures**

The repository includes PNG images of the eight graphs, as seen in our report, generated by the R script, these are named `Graph1.png` through `Graph8.png`and correspond to the graph headimgs in the R script.

## Running the Analysis

1. Download or clone the repository.
2. Open the `.Rproj` file in RStudio.
3. Ensure that both Excel datasets are in the project directory, with the exact file names specified above.
4. Open `BioCode_2(2).R`.
5. Click **Source** to run the complete analysis.

The script installs any missing required R packages, tests and fits all models required for our study, generates figures and performs diagnostics.

**Note:** Model fitting and simulation-based diagnostics may take several minutes to complete.
